🎨 PRC-721 NFT 合集发射器
在 Paxi Network 上创建你的 NFT 合集。无需编写智能合约代码——填写信息、上传图片、一键部署。 NFT 合约将部署到 Paxi 主网，完全归你控制。
💡 工作原理：你填写的 NFT 元数据将随合约部署到链上。图片存储在合约元数据中（Base64 编码）。 合约部署后，你可以通过 Mint 功能铸造 NFT 给任何人。支持设置版税（二次交易分成）。
